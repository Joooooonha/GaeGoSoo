## 성공 기준 답변

**SSH는 무엇인가?**
다른 컴퓨터의 셸에 접속하기 위해 사용하는 네트워크 프로토콜. TCP(주로 22번 포트) 위에서 동작하는 응용 계층 프로토콜로, TCP/IP가 "데이터를 안전하고 순서대로 옮기는 전달 수단"이라면 SSH는 그 위에 얹힌 "암호화 + 키 기반 로그인 인증 + 원격 명령 실행 규약"이다. 평문으로 보내던 Telnet의 암호화 버전이라고 볼 수 있다.

**`/`, `/home`, `/etc`, `/var`, `/tmp`는 어떤 역할인가?**
- `/` : 최상위 절대 경로이자 디렉토리 구분자
- `/home` : 일반 사용자 홈 디렉토리
- `/etc` : 시스템/애플리케이션 설정 파일 — 로그처럼 계속 쌓이는 게 아니라 사람이 편집하는 성격의 파일들
- `/var` : 로그, 캐시 등 실행 중 계속 변하는 데이터
- `/tmp` : 임시 파일 저장소

**상대 경로와 절대 경로의 차이는?**
절대경로는 현재 위치(`pwd`)와 무관하게 항상 같은 대상을 가리키고, 상대경로는 현재 위치를 기준점으로 삼기 때문에 같은 문자열이라도 `pwd`가 다르면 다른 대상을 가리킬 수 있다.

## 추가로 짚은 개념

- **SSH vs TCP/IP**: TCP/IP는 계층화된 전달 수단(IP=주소/라우팅, TCP=신뢰성 있는 순서 보장 전달)이고, SSH는 TCP 연결 위에서 도는 응용 계층 프로토콜. OSI 기준으로 IP=3계층, TCP=4계층, SSH=7계층.
